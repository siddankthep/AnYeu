# Windows Cheatsheet for MacBook Users

A guide to help you transition from macOS to Windows.

## 1. The Keyboard Translation

The most important change to remember is the primary modifier key.

| macOS Key     | Windows Equivalent | Description                                                     |
| :------------ | :----------------- | :-------------------------------------------------------------- |
| `Command (⌘)` | `Control (Ctrl)`   | The main key for most shortcuts.                                |
| `Option (⌥)`  | `Alt`              | The secondary modifier key.                                     |
| `Control`     | `Windows key (⊞)`  | Used for OS-specific functions and shortcuts.                   |
| `Delete`      | `Backspace`        | Deletes characters to the left of the cursor.                   |
| `fn + Delete` | `Delete`           | Deletes characters to the right of the cursor (forward delete). |

## 2. Essential System & App Shortcuts

These are the fundamental commands for everyday tasks.

| Task/Function                 | macOS Shortcut     | **Windows Shortcut**                                   |
| :---------------------------- | :----------------- | :----------------------------------------------------- |
| **Copy**                      | `⌘ + C`            | `Ctrl + C`                                             |
| **Paste**                     | `⌘ + V`            | `Ctrl + V`                                             |
| **Open Clipboard**            | `Unknown`          | `Windows key (⊞) + V`                                  |
| **Cut**                       | `⌘ + X`            | `Ctrl + X`                                             |
| **Undo**                      | `⌘ + Z`            | `Ctrl + Z`                                             |
| **Redo**                      | `⌘ + Shift + Z`    | `Ctrl + Y`                                             |
| **Select All**                | `⌘ + A`            | `Ctrl + A`                                             |
| **Save**                      | `⌘ + S`            | `Ctrl + S`                                             |
| **Print**                     | `⌘ + P`            | `Ctrl + P`                                             |
| **Find Text**                 | `⌘ + F`            | `Ctrl + F`                                             |
| **Open New Window**           | `⌘ + N`            | `Ctrl + N`                                             |
| **Close Current Window**      | `⌘ + W`            | `Ctrl + W` or `Ctrl + F4`                              |
| **Quit Application**          | `⌘ + Q`            | `Alt + F4`                                             |
| **Switch Between Open Apps**  | `⌘ + Tab`          | `Alt + Tab`                                            |

| **Open Preferences/Settings** | `⌘ + ,` (Comma)    | Varies by app, but often `Ctrl + ,` or found in menus. |

## 3. Searching for Files & Apps (The "Spotlight" Alternative)

Windows Search is the direct equivalent to Spotlight for finding anything on your computer.

| Task/Function            | How to do it on macOS           | **How to do it on Windows**                                     |
| :----------------------- | :------------------------------ | :-------------------------------------------------------------- |
| **Universal Search**     | Press `⌘ + Spacebar`            | Press the `Windows key (⊞)` and start typing.                   |
| **File Explorer Search** | Open Finder, use the search bar | Open File Explorer (`Windows key (⊞) + E`), use the search bar. |

## 4. Screenshots & Screen Recording

Windows has a built-in "Snipping Tool" that combines all of these functions.

| Task/Function                    | macOS Shortcut                   | **Windows Shortcut / Method**                                  |
| :------------------------------- | :------------------------------- | :------------------------------------------------------------- |
| **Screenshot a Specific Area**   | `⌘ + Shift + 4`                  | `Windows key (⊞) + Shift + S`                                  |
| **Screenshot the Entire Screen** | `⌘ + Shift + 3`                  | `PrtScn` key (copies to clipboard)                             |
| **Screenshot & Save File**       | `⌘ + Shift + 3`                  | `Windows key (⊞) + PrtScn` (saves to Pictures/Screenshots)     |
| **Screenshot the Active Window** | `⌘ + Shift + 4`, then `Spacebar` | `Alt + PrtScn`                                                 |
| **Screen Record Video**          | `⌘ + Shift + 5`                  | Open **Snipping Tool** app, switch to the video recorder icon. |

## 6. Trackpad Gestures

Windows has modern trackpad support that mirrors the macOS experience.

| Task/Function             | macOS Gesture                        | **Windows Gesture**                                |
| :------------------------ | :----------------------------------- | :------------------------------------------------- |
| **Scroll**                | Two-finger slide                     | Two-finger slide (vertically or horizontally)      |
| **Zoom In / Out**         | Two-finger pinch                     | Two-finger pinch or stretch                        |
| **Show All Open Windows** | Swipe up with 3 or 4 fingers         | Swipe up with three fingers                        |
| **Show Desktop**          | Spread with thumb and 3 fingers      | Swipe down with three fingers                      |
| **Switch Between Apps**   | Swipe left/right with 3 or 4 fingers | Swipe left or right with three fingers             |
| **Right-Click**           | Two-finger tap or press              | Two-finger tap or press in the bottom-right corner |
